# Competitor & Reference Screens

Primary source for all visual references is **Mobbin**. Always prefer opening the live screens there rather than relying on static images (Mobbin content updates).

## Core Competitors / Examples

### Monarch Money (strongest bookkeeping reference)
- Full finance dashboard with budget progress bars, spending comparison, net worth, transactions, recurring.
- Mobbin: https://mobbin.com/explore/screens/a2852c69-d3f2-45cb-b3fd-c6fadfc47977
- Official site for additional context: https://www.monarchmoney.com
- Patterns to extract: modular widgets, remaining-budget indicators, clean transaction list, net-worth trend.

### Whop (creator / SaaS analytics style)
- KPI cards for gross revenue, net revenue, new users with sparklines and date comparison.
- Appears frequently in Mobbin Analytics Dashboard collection.
- Collection entry point: https://mobbin.com/explore/web/screens/analytics-dashboard
- Patterns: customizable widget layout, clear positive/negative deltas, filterable time ranges.

### Analytics collection (broad set)
- Includes examples from Navattic, HubSpot-style, Amplitude-inspired, Pinterest analytics, Base44, etc.
- Entry: https://mobbin.com/explore/web/screens/analytics-dashboard
- Useful for pure analytics layouts (traffic sources, device breakdowns, performance-over-time).

### ERP / Accounting (Xero and similar)
- More formal bookkeeping / business operations dashboards.
- Entry: https://mobbin.com/explore/web/screens/erp-system-dashboard
- Patterns: invoice/quote/revenue overview cards, notification panels, schedule views.

## How to Capture Fresh Screenshots

When the user requests visual references or a moodboard with images:

1. Use the browser tools to open the relevant Mobbin screen URL.
2. Take a desktop screenshot of the page (or the embedded dashboard preview).
3. Describe the layout, colors, and hierarchy in text so the response remains useful even without the image.
4. Link the exact Mobbin URL so the user can explore the full interactive screen and related flows.

Do not host or redistribute full Mobbin screenshots outside the conversation unless the user explicitly needs a static export for their own design files. Prefer directing them to Mobbin for the highest-fidelity, up-to-date references.
